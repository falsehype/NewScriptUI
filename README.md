# Midnight-UI

### A compact, dark Roblox UI project built with Luau.

A minimal dark interface with animated controls, draggable and resizable windows, responsive groupboxes, dropdowns, sliders, an HSV color picker, and per-toggle key settings.

## Get started

1. Download [Midnight-UI.txt](src/Midnight-UI.txt).
2. Open Roblox Studio and create a **LocalScript** under `StarterPlayer > StarterPlayerScripts`.
3. Copy the downloaded text into the LocalScript.
4. Start a client play test. Press `RightShift` to hide or show the UI.

## Project status

Midnight-UI is currently a single-file demo script. The reusable `CreateWindow()` / `AddToggle()` library API is still being developed, so the downloaded script creates the example interface directly.
