## Get started

1. Download [Midnight-UI.txt](src/Midnight-UI.txt).
2. Create a **LocalScript** under `StarterPlayer > StarterPlayerScripts` in Roblox Studio.
3. Paste the downloaded text into the LocalScript and start a client test.
4. Press `RightShift` to hide or show the UI.
