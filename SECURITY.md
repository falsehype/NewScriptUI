# Security policy

## Supported versions

Security reports should target the latest code on the default branch. There are no stable releases yet.

## Reporting a problem

Do not publish credentials, cookies, session tokens, or other secrets in a public issue. For a sensitive report, contact the repository owner privately through a contact method listed on their GitHub profile.

## Safe use

Review code before adding it to an experience. Do not use this project to disrupt other Roblox experiences, bypass experience rules, or interfere with other players. Never paste private credentials into the project or its issue tracker.
