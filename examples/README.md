# Examples

The current source is a standalone preset script. For a normal Roblox Studio test, follow [Studio setup](StudioSetup.md).

The primary demo toggles include optional settings menus with keybind capture and three activation modes. See [Toggle settings](../docs/TOGGLE_SETTINGS.md) for setup and behavior.\n\nThe current prototype does not return a configurable library object. See [API status](../docs/API_STATUS.md) before writing code against the planned API.
